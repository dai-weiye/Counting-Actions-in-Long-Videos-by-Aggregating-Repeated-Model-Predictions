# Open-weight evaluation on the full official MLVU Action Count test split

This extension uses all 60 official test videos, their original six numeric options and the fixed Qwen2-VL-2B-Instruct checkpoint from the completed 32-question development control. The roster, official source video hashes, settings and analysis are fixed before this study generates any test response or accesses any test label. The 128-frame DeepSeek study uses independent response records and a separate collection protocol.

For each video, make four independent Qwen forward passes in the order U1, U2, U3, C4. Use the same 4-bit checkpoint at revision `01af461cdb9574acc09084a0ef94e216e142b085` and exactly the development control's `select_frames`, `prompt` and `execute` functions. U1 to U3 receive 16 identical uniformly spaced frames. C4 receives 16 frames selected for change within a pool of 32. Resize each image to a maximum side of 224 using Lanczos. Preserve temporal order, the original question stem and the published ordering of all six choices. Decode greedily, reset the MLX seed to zero per call and limit output to eight new tokens. Accept a response only when its stripped final text equals an offered numeric option. Keep blank and unsupported answers. A completed generation closes its slot. Verify all source video and model file hashes and archive input indices, resized RGB hashes, formatted prompt hashes and all final responses.

Score candidate counts from 1 to 5 by summing minus twice the absolute error plus one for an exact match with each response. Select the smallest maximizing count. For videos with all four usable responses, compare the four-report estimate with the raw first count. Report exact accuracy, MAE, paired corrections and losses, exact McNemar p, and a 20,000-resample paired-question bootstrap interval (seed zero). Additional prespecified comparisons use the first prediction clipped to the same candidate range and apply the same four-report scorer over the six offered options. Report the three-call identical-input disagreement rate, C4 changes from U1, and whether the aggregate equals the range-matched U1. Over all 60 videos, report accepted slots and correct-answer yields for the first call, complete four-report aggregation, and all available reports. For the fixed integer estimator, replay the exact sequential stopping certificate against all 240 recorded responses, including blank outcomes. Report calls saved and equality to the all-available four-slot decision on each question. As a video-duration control, score the development-trained tree’s 60 predictions fixed in the unlabelled test roster. The test model outputs will be locked by a SHA-256 digest before a separate scoring process reads the public labels. The release includes these model predictions, aggregate scores and the 60 public count labels needed for offline replay. Keep this model's 16-frame results separate from the API's 128-frame results.
