# Untuned evaluation on MLVU Test Action Count

The official MLVU repository announced the release of the test answers on 18 March 2025. This study uses the public test files specified by the linked lmms-eval task, sy1998/MLVU_Test revision 4a9826be2bc6c86f9cab9222a06a55c224098958. The protocol was fixed before accessing test answers or running any test inference. Only the column names, question wording, number of options, number of items and file listings were inspected.

Include all 60 questions with task_type=count. Use the published video and original order of the six numeric options in each question. Extract the question stem and reconstruct the project's numeric-answer prompt. Use one frozen API alias (deepseek-flash) and four real requests per video: three identical 128-frame uniform inputs (U1, U2, U3) and the 128 frames with the largest visual changes from 256 uniformly sampled frames (C4). Preserve original temporal order, color/JPEG encoding, temperature zero, thinking enabled and 8,192-token limit. Alternate first-slot allocation by cyclically rotating the four slot labels across videos sorted by numeric question ID; each video's first baseline remains the preassigned U1 slot. Only final text exactly equal to a listed option after stripping whitespace is accepted. Keep blank finals, invalid finals and unsuccessful calls as terminal outcomes. Up to five identical transport attempts per slot for transient network/HTTP failures. No repeat after a complete model response. Do not use the label or video duration in any prompt, retry decision, frame selection, or parameter choice.

The primary paired comparison uses every video with four accepted reports. Compare the aggregate of all four to the raw numerical U1 response on the same videos. Use the published developer-fitted coefficients (0.8,0.8,0.4), exact integer arithmetic and smallest maximizing count on ties. Candidate range stays 1 through 5 even on the six-option test; U1 can take any offered number. Report exact-count accuracy, mean absolute error, wins, losses, two-sided exact McNemar test and a paired 95% percentile bootstrap interval (20,000 paired-question resamples, NumPy seed zero). Report the accepted counts in each slot and the number of videos where each system produced a correct answer among all 60 assigned questions, with a missing required response treated as unanswered. Separately report a prespecified fallback that uses all available reports with the same fixed rule, leaving an item unanswered if all four reports are missing. Sensitivity on complete cases includes exact-largest ties, historical floating point, first-encounter majority, rounded median, and the first three uniform reports. Distinguish the named U1 baseline from an order-selected best call.

As an independent benchmark diagnostic, fit the original depth-three duration-only tree on all 206 development questions with scikit-learn random_state=0, freeze it, then score the 60 public test durations without refitting. The prediction stage for both experiments cannot read test labels. Join final predictions to the released letters only in the scoring stage after all slots finish. Report available accuracy and failures regardless of direction. A single provider and 60 test questions define the scope of the video result.
