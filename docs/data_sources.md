# Data sources

## Benchmark records

MLVU Action Count asks how often a reference action occurs in a longer video. This release contains item-level numeric records, frame indices, checksums and analysis code. Videos, model weights and free-form model generations are excluded. Benchmark-derived annotations retain the MLVU terms. [Third-party notices](../THIRD_PARTY_NOTICES.md) · [MLVU paper](https://openaccess.thecvf.com/content/CVPR2025/html/Zhou_MLVU_Benchmarking_Multi-task_Long_Video_Understanding_CVPR_2025_paper.html)

| Records | Source and transformation |
|---|---|
| [Development counting](../data/action_count.csv) | The 206 rows follow the public `4_count.json` annotation order. Each row joins the video basename, reference count and duration to the study’s parsed predictions and available usage measurements. The parameter fit and held-out analysis each use 103 videos. Sorting by filename and permuting with NumPy seed zero reconstructs the split. [Split procedure](../held_out_errors/README.md) |
| [Development reasoning controls](../data/reasoning.csv) | The 237 event-order items and 329 needle-localization items use the one-based row number within their source annotation. The gold and predicted answer columns contain zero-based option indices. [Annotation and run checksums](../data/source_checksums.json) |
| [Official test counting](../external_eval/items.json) | All 60 Action Count items carry the public question ID, video filename, six options in their original order, reference count and duration. The MLVU authors announced the release of test answers on 18 March 2025. We used the published lmms-eval distribution at revision `4a9826be2bc6c86f9cab9222a06a55c224098958`. The manifest identifies the annotation parquet and video archives by SHA-256. [Maintainers’ announcement](https://github.com/JUNJIE99/MLVU) · [Pinned distribution](https://huggingface.co/datasets/sy1998/MLVU_Test/tree/4a9826be2bc6c86f9cab9222a06a55c224098958) · [Source manifest](../external_eval/video_sources.json) |

The development annotation hashes cover `4_count.json`, `5_order.json` and `2_needle.json`. The fourth-call control separately records the development video revision and hashes. To acquire media, start with the upstream releases and their research-use terms. [Annotation checksums](../data/source_checksums.json) · [Development video manifest](../fourth_call/video_sources.json) · [Development release](https://huggingface.co/datasets/MLVU/MVLU) · [Official test release](https://huggingface.co/datasets/MLVU/MLVU_Test)

## Model outputs and external results

- **DeepSeek.** The archived development run configurations identify the requested alias. The official test service record gives `deepseek-flash` as both requested and returned for all 240 slots, along with the returned service fingerprint and collection dates. The terminal records preserve parsed counts and response status. U1, U2 and U3 use the same uniform frames. C4 uses change-selected frames. [Development settings](../data/runs.json) · [Test service record](../provenance/model_service.json) · [Test slot observations](../external_eval/calls.jsonl) · [Selected indices](../external_eval/selected_frames.jsonl)
- **Qwen.** The open-weight comparison used the MLX community’s 4-bit conversion of Qwen2-VL-2B-Instruct at revision `01af461cdb9574acc09084a0ef94e216e142b085`. Per-study manifests record the software environment and decoding settings. Offline replay uses the recorded predictions. Rerunning inference requires acquiring the checkpoint from its distributor. [Test runtime](../open_weight_test/runtime.json) · [Pinned checkpoint](https://huggingface.co/mlx-community/Qwen2-VL-2B-Instruct-4bit/tree/01af461cdb9574acc09084a0ef94e216e142b085)
- **Scoring.** The fixed decoder considers candidate counts 1 through 5. The offered-option analysis uses the choices in the individual question, which can include 0 or 6. The development error analysis replays the archived floating-point estimator on the held-out 103 items. The exact-stopping analysis uses the integer score and lower-count tie rule. Its replay tests what would happen if inference stopped early on the acquired four-slot sequence. [Held-out analysis](../held_out_errors/README.md) · [Exact-stopping protocol](../exact_stopping/README.md)
- **Published baselines.** The table transcribes Action Count accuracy for six baselines. The source index identifies the publication, table or figure, split, and input protocol for each transcribed number. [Reported results](../published_baselines/reported_results.csv) · [Publication sources](../published_baselines/sources.json)
