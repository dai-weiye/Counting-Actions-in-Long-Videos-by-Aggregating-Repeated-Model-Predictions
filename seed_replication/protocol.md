# Repeated four-seed groups on MLVU Action Count

This plan is fixed before acquiring new model predictions. The author has seen earlier MLVU development results. The new study estimates variation across independently drawn frame-sampling groups for a fixed set of videos, with the historical model alias and today's service. Each group uses four new model calls on four independently sampled sets of 128 frames. All groups use the same videos.

## Sampling

Recreate the 103 questions held out from fitting: sort the 206 public development filenames lexicographically, permute with NumPy default_rng(0), and take the last 103 indices. Rank those questions by the SHA-256 digest of the UTF-8 string `MLVU seed replication | FILENAME`, including the extension. Select the first 32. Draw without access to labels, previous responses or video availability. Record the filenames before contacting the API. Recover a missing video from the recorded public source. Keep its slot if acquisition fails.

Use six disjoint groups, each containing four seed streams. NumPy SeedSequence(20261124).spawn(24) defines the streams in group-major and within-group order. For each stream use PCG64 to draw 128 positions without replacement from a 256-position pool and retain them in temporal order. As in the earlier seeded experiment, a stream uses the same relative positions across videos. For N decoded frames the pool is numpy.linspace(0, N-1, 256).astype(int). Store each position list and all 768 absolute frame-index lists. Pool decoding must succeed at every selected index; keep a decoding failure as a distinct status.

Use the same model alias (deepseek-flash), prompt, listed choices and JPEG encoding as the archived main experiment. Use temperature zero, reasoning enabled and a limit of 8192 output tokens. Interleave streams in a separate precomputed PCG64 order (seed 20261125) over video/stream pairs; all groups are spread across acquisition time. A final trimmed response must match one of the four offered numbers. Keep blank and unsupported finals. A completed model response, including an empty final, closes the slot. For transport failures or transient HTTP 429/5xx responses, send the identical payload at most five times in total. Capture status, termination reason, time, model/fingerprint and payload hash. Pause on authentication or payment errors.

## Endpoints

Use the fixed exact-integer score summed over reports, -2|report-c| + 1[report=c], for candidates 1 through 5. On ties take the smaller candidate. The four reports are ordered by stream index. The primary comparator is the expected accuracy of one uniformly chosen call from the same four, estimated by their arithmetic mean. This uses every single report symmetrically. Positive gain favors four-report aggregation. Calculate each group's aggregate score, mean single score and gain on the same questions. Report all six gains and their sample SD (ddof=1) and range. The primary common cohort consists of questions with four valid final answers in every group. Report its exact size and IDs. If it is empty the complete-case group dispersion is undefined. Replication varies frame selection and model execution together.

Also report per-group four-valid complete-case comparisons, first ordered call, best of the four single-call accuracies, majority vote with first-encounter tie resolution, the highest maximizing candidate, and the archived floating-point rule. On all 32 planned questions report correct-answer yield when a missing final counts as unanswered: a four-report output requires four valid finals, while a single-call output requires only that call's final. As a distinct fixed fallback, apply the same integer scorer to all valid reports, with no output when all four are missing. Report agreement and counts of each completion status. Use paired question bootstrap intervals for the prespecified mean gain averaged over the six groups, resampling complete common questions 20,000 times with PCG64 seed zero and percentile endpoints at 2.5 and 97.5. Groups share questions and are never treated as independent video samples.

The public artifact retains item IDs, producer hashes, all source frames, per-call final counts/status/finish reasons and offline analysis. Separately label historical runs with missing frames or unknown old hash salts. The new experiment has independently reconstructable input selection. It cannot identify the old indices.

The initial working draft specified four groups and 24 questions. Before any new model call or accuracy analysis, the confirmed budget extended this to six groups and the first 32 questions in the same predeclared rank order. No item was removed or reordered.
